# 🏦 ATM Simulation System (Python)

This is a beginner-friendly Python mini project that simulates the working of an ATM machine.

## 📌 Project Overview

The system allows a user to:
- Authenticate using account holder name and PIN
- Check account balance
- Withdraw money
- Deposit money
- Exit the system

## 🛠️ Concepts Used

- Variables
- User Input
- Conditional Statements (if-elif-else)
- Menu-driven programs
- Arithmetic operations
